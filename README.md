# Spes Therapy

Website for Spes Therapy, built with plain HTML, CSS and JavaScript.

🌐 [spestherapy.com](https://spestherapy.com)

## Features

- Responsive single-page layout
- Scroll animations and marquee banner
- Online booking via [Cal.com](https://cal.com)
- Contact form via [Web3Forms](https://web3forms.com)

## Structure

```
├── index.html
├── english-privacy-policy.html
├── booking-payment-policy.html
├── css/style.css
├── js/main.js
└── images/
```

## Running locally

Open the folder with VS Code's **Live Server** extension, or run:

```bash
python -m http.server 5500
```

## Deployment

Deployed on Netlify. Every push to `main` is published automatically.
